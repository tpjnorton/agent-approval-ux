# Project rules

## Git

- Never run `git commit`. Staging with `git add` is fine. Tom commits.
- Never push.

## Tooling

- The demo uses pnpm, pinned with the `packageManager` field. Never introduce npm or yarn lockfiles.
- `pnpm dev` and `pnpm build` inline the sync step, because pnpm does not run `pre`/`post` scripts by default.

## Layout

- The product is `skills/agent-approval-ux/`. Rules in `SKILL.md`, argument in `references/rationale.md`.
- `demo/` is a Next.js app. `demo/lib/skill/` is generated by `pnpm sync` from `skills/agent-approval-ux/examples/shared/` and is gitignored. Edit the source in `examples/shared/`, never the copy.
- Framework examples in `examples/{ai-sdk,ag-ui,mcp}` are illustrative and typechecked against pinned versions noted in each README. They are not built by the demo.

## Writing

- Rules in `SKILL.md` are terse instructions to an agent. Rationale goes in `references/rationale.md`, never inline.
- Follow the writing style in the user-level CLAUDE.md for all prose.
